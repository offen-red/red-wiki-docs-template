# `red-doc` 제안 블록 — 문법은 여기 하나뿐이다

채팅은 파일을 쓰지 않는다. 대신 이 블록을 낸다. 뷰어가 **검토 카드**로 그리고, 저장은 사람이 버튼으로 한다.

**이 파일이 유일한 규격이다.** 한때 `ask`·`draft`·`decision`·`ingest` 네 스킬이 각자 문법을 적어 두었는데, 파서(`src/components/workbench/DocProposal.tsx`)까지 치면 같은 규격이 다섯 곳에 있었다. 하나를 바꾸면 나머지가 조용히 어긋난다. **문법을 고칠 일이 생기면 파서와 이 파일 둘만 고친다.**

## 형식

````
```red-doc
@path docs/ops/tooling/kiwi-ai.md
---
title: Kiwi AI
type: doc
status: 작성중
owner: 수빈
---
본문…
```
````

- **파일 하나에 블록 하나.**
- `@path` 가 **맨 위**다. `@키 값` 줄이 이어지다 `@` 로 시작하지 않는 첫 줄에서 머리말이 끝나고, 그 아래가 통째로 문서 원문이 된다.
- 블록 밖에 같은 본문을 또 적지 않는다. 블록 **위**에 무엇을 왜 이렇게 썼는지 두세 문장만 적는다.

## 파서가 거절하는 것

아래에 걸리면 카드가 이유를 띄우고 저장 버튼이 잠긴다. 미리 맞춰서 낸다.

| 조건 | 이유 |
| --- | --- |
| `@path` 없음 | 어디에 쓸지 모른다 |
| `docs/` 로 시작하지 않음 | 뷰어는 `docs/` 밖을 렌더하지 않는다 |
| `.md` 가 아님 | 마크다운만 만든다 |
| `docs/_sources/` 아래 | 원천은 사람이 던지는 불변 층이다 — 여기서 만들지 않는다 |
| 경로에 대문자·한글 | 영문 kebab-case 다 (`^[a-z0-9/_.-]+$`) |
| frontmatter 없음 | |
| `title` · `status` · `owner` 중 하나라도 빔 | 사람이 채우는 필수 셋이다. `owner` 를 모르면 비우지 말고 **묻는다** |
| frontmatter 에 `mirror:` | 노션이 원본인 미러다 — 노션에서 고쳐야 한다 |

`type` 은 frontmatter 에 넣는다(`doc` · `guide` · `hub`). 뷰어가 이 값으로 폼을 고른다.

## 예외 둘

**`@path registry.yaml`** — 문서가 아니라서 위 규칙을 적용하지 않는다. 폼이 없어 **복사만** 된다. 새 문서를 만들면서 `registry.yaml` 을 안 채우면 `/ask` 가 그 문서를 못 찾으므로, 필요하면 블록을 하나 더 낸다.

**`docs/decisions/<날짜>-<슬러그>.md`** — 이 모양일 때만 카드에 **[바로 저장]** 이 붙는다. 경로·파일명·모양이 스킬에서 이미 정해져 폼에서 더 정할 것이 없고, 결정은 습관이 되어야 값이 나기 때문이다. 새 파일일 때만이고 이미 있으면 서버가 409 로 거절한다.

## AI 가 쓴 문서라는 표시

**문서 근거가 아니라 대화에서 나온 내용이 섞였으면** frontmatter 에 셋을 넣는다.

```yaml
generated: true # 사람이 검토하면 지운다
from: [실제로 읽은 문서 경로, ...] # 비면 지어낸 것이다
asked: "<원래 질문 그대로>"
```

원천 문서를 정리한 것뿐이면 `generated` 는 붙이지 않는다. **이 표시가 남아야 팀이 "이건 AI 가 쓴 것"을 구분한다** — 안 붙이면 사람이 쓴 문서와 섞여 다음 답의 근거가 된다.
