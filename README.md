# red-wiki-docs-template

새 문서 저장소를 찍어 내는 뼈대입니다. **이 저장소 자체는 문서를 담지 않습니다.**

문서는 [Red Kiwi](https://github.com/offen-red/red-wiki-desktop) 앱에서 읽고 쓰고 검토에
올립니다. 이 저장소가 하는 일은 앱이 위키로 알아볼 수 있는 최소한의 뼈대를 주는 것뿐입니다.

## 만드는 법

**1. 이 템플릿으로 새 저장소를 만듭니다.**

이름은 **`red-wiki-docs-<제품>`** 이어야 합니다. 앱이 GitHub 저장소 목록에서 이 접두사로
위키를 찾고, 접두사를 뗀 `<제품>` 을 그대로 씁니다 — 사이드바 최상위 이름이자 문서 경로의
첫 조각입니다(`iasm/product/overview.md`).

> `-template` 로 끝나는 이름은 앱이 목록에서 건너뜁니다. 그래서 이 저장소는 앱에 안 뜹니다.

**2. `registry.yaml` 의 세 칸을 채웁니다.**

| 칸 | 무엇 |
| --- | --- |
| `product.label` · `summary` | 제품 이름과 한 줄 설명 |
| `scope` | **이 저장소가 무엇을 담는가.** 앱이 알 수 없는 유일한 사실입니다 |

`scope` 는 저장소가 여럿 열려 있을 때 **새 문서를 어디에 둘지** 판단하는 근거입니다.
비워 두면 AI 가 이 저장소를 후보에서 빼고, 여기 둘 문서를 다른 저장소에 제안합니다.


**`screens:` 와 `nav:` 는 손대지 마세요.** 
- 문서를 쓰면 자동으로 하나씩 추가됩니다. 


## 담기는 것

```
docs/product/     이 저장소가 담는 지식
docs/decisions/   왜 그렇게 정했나 — 대화에서만 나온 것
registry.yaml     이 저장소가 아는 어휘 + scope
```

폴더 구성은 저장소가 정합니다. 여기 둘은 시작점일 뿐이고, 문서를 쓰면서 앱의 폼에서
늘리면 됩니다.

---

**이 README 는 템플릿의 것입니다.** 저장소를 만들었으면 지우거나, 그 저장소가 무엇을
담는지 설명하는 글로 바꿉니다 — 새 저장소에 「만드는 법」이 남아 있으면 이미 만든 사람이
다시 읽게 됩니다.
